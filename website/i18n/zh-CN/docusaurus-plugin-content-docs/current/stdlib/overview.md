# 标准库概览

Zerolang 的标准库设计目标是覆盖大多数程序的常见需求，减少对外部依赖的搜索。

## 已记录模块

| 模块 | 说明 |
|---|---|
| `std.args` | 命令行参数解析 |
| `std.env` | 环境变量访问 |
| `std.fs` | 文件系统操作 |
| `std.crypto` | 加密相关 |
| `std.http` | HTTP 客户端 |
| `std.net` | 网络操作 |

## 设计原则

- 所有外部访问都通过显式 capability
- 稳定 API 让副作用、所有权和清理操作可见
- 目标中立的包应将与文件系统相关的代码放在跨平台入口点之外
