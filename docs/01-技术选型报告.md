## 一、Zerolang 是什么

**Zerolang** 是 Vercel Labs 于 2026 年 5 月推出的实验性系统编程语言，目前版本 v0.1.4，Apache-2.0 协议。

核心定位：**"面向 AI Agent 的编程语言"**

- 编译器输出结构化 JSON 诊断信息
- 提供机器可读的修复计划（`zero fix --plan --json`）
- Agent 可直接理解错误并自动修复，无需解析人类可读文本
- 编译为原生可执行文件，目标 sub-10 KiB 二进制
- 显式内存管理、无隐藏分配器、无隐式异步

官网：https://zerolang.ai  
GitHub：https://github.com/vercel-labs/zerolang

## 四、推荐方案：Docusaurus 3.x

### 推荐理由

**1. 对标 Mojo 中文网，路径最清晰**

Mojo 中文网已经用 Docusaurus 跑通了整套中文编程语言社区站的模式。直接复用这套模式，少走弯路。

**2. 编程语言文档的刚需功能全覆盖**

- **版本管理**：Zerolang 目前 v0.1.x，未来快速迭代，内置版本切换能让用户查看不同版本文档
- **多语言 i18n**：中文版和英文版共存，翻译工作流成熟
- **搜索**：Algolia DocSearch 免费接入，中文搜索体验好
- **暗色模式**：开发者文档标配
- **代码高亮**：Prism 支持自定义 Zerolang 语法高亮（`.0` 文件）

**3. MDX 交互组件想象空间大**

Zerolang 强调"graph-first"和 agent 工作流，可用 React 组件嵌入：
- 交互式 `zero graph --json` 输出可视化
- `zero check` 诊断结果的折叠/展开面板
- 编译命令的一键复制按钮

**4. 部署零成本**

GitHub Actions + GitHub Pages 完全免费，或部署到 Vercel（Zerolang 就是 Vercel Labs 项目）。

### 备选方案

| 场景 | 推荐 |
|---|---|
| 极致性能、页面秒开 | Astro + Starlight |
| Vue 开发者、排斥 React | VitePress |
| 完全自定义官网视觉 | Next.js + Nextra 3 |
| 轻量文档站、不折腾 | VitePress 或 MkDocs |

## 五、整体架构

```
zerolang-cn/
├── docs/                 # 中文文档翻译
│   ├── getting-started/
│   ├── language/
│   ├── cli/
│   ├── stdlib/
│   └── examples/
├── blog/                 # 社区博客/更新日志
├── src/pages/            # 自定义页面（首页、关于）
├── static/               # 静态资源
├── i18n/                 # 多语言翻译文件
├── docusaurus.config.ts  # 站点配置
└── .github/workflows/    # CI/CD 自动部署
```

## 六、起步命令

```bash
npx create-docusaurus@latest zerolang-cn classic --typescript
cd zerolang-cn
npm run start
```
