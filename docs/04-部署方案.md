# 部署方案

> Zerolang 社区站部署与运维指南（v4 — Cloudflare Pages 主方案）

## 一、部署目标

| 环境 | 地址 | 说明 |
|---|---|---|
| 开发环境 | localhost:3000 | `npm run start`（英文默认） |
| 开发环境（中文） | localhost:3000 | `npm run start:zh` |
| 预览环境 | localhost:3000 | `npm run build && npm run serve`（所有语言） |
| 生产环境 | https://zerolang.app | **Cloudflare Pages** + 自定义域名 |
| 生产环境（备选）| https://zerolang.app | Vercel + 自定义域名 |
| 生产环境（备选）| https://zerolang.app | GitHub Pages + 自定义域名 |

```

│   ├── 01-技术选型报告.md

│   ├── 03-内容策略.md
│   ├── 04-部署方案.md
│   ├── 05-部署指南.md
│   ├── 06-架构设计.md
│   └── 07-Cloudflare-Pages-评估.md
└── website/                   # Docusaurus 站点源码
    ├── config/                # 模块化配置
    ├── docs/                  # 英文文档（默认语言）
    ├── blog/                  # 英文博客
    ├── i18n/zh-CN/           # 中文翻译内容
```

所有构建命令需在 `website/` 目录下执行。

## 四、方案 A：Cloudflare Pages（推荐主方案）

选择 Cloudflare Pages 作为主方案的原因：

- **域名已在 Cloudflare 管理**：绑定 `zerolang.app` 零配置，一键激活
- **全球 CDN 最强**：230+ 城市节点，Anycast 网络，比 Vercel 覆盖更广
- **一体化管理**：DNS + Pages + CDN + Analytics 全在一个平台
- **免费额度 generous**：无限请求、无限带宽（合理使用范围内）

### 4.1 连接仓库

1. 登录 [dash.cloudflare.com](https://dash.cloudflare.com)
2. 左侧菜单 **Workers & Pages** → **Create application** → **Pages** → **Connect to Git**
3. 授权 GitHub，选择 `zerolang` 仓库，点击 **Begin setup**

### 4.2 配置构建

| 配置项 | 值 |
|---|---|
| Project name | `zerolang`（或你喜欢的名字） |
| Production branch | `master` |
| Framework preset | **None** |
| Build command | `cd website && npm install && npm run build` |
| Build output directory | `website/build` |
| Root directory | `/`（留空或不填） |

> Cloudflare Pages 的构建命令在仓库根目录执行，所以需要 `cd website` 进入子目录后再运行 npm 命令。

点击 **Save and Deploy**，首次部署约 2-3 分钟。

### 4.3 绑定自定义域名 `zerolang.app`

**域名在 Cloudflare 管理（你的情况）：**

1. 进入 Pages 项目 → **Custom domains**
2. 输入 `zerolang.app`，点击 **Continue**
3. 点击 **Activate domain**
4. Cloudflare 自动完成 DNS 配置和证书签发，**无需手动添加任何记录**

**域名不在 Cloudflare：**

1. 进入 Pages 项目 → **Custom domains**
2. 输入 `zerolang.app`，点击 **Continue**
3. Cloudflare 会显示需要添加的 DNS 记录（通常是 CNAME）
4. 去域名服务商处添加对应记录
5. 等待生效

### 4.4 验证部署

部署完成后，检查以下 URL：

| URL | 预期内容 |
|---|---|
| `https://zerolang.app/` | 英文首页 |
| `https://zerolang.app/docs/intro/` | 英文文档首页 |
| `https://zerolang.app/zh-CN/` | 中文首页 |
| `https://zerolang.app/zh-CN/docs/intro/` | 中文文档首页 |

### 4.5 分支预览

Cloudflare Pages 自动为每个 Pull Request 生成预览地址，格式为：

```
https://[branch-name].zerolang.pages.dev
```

方便在合并前预览修改效果。

## 五、方案 B：Vercel（备选）

如果 Cloudflare Pages 遇到构建问题，可快速切换到 Vercel。

### 5.1 连接仓库

1. 登录 [vercel.com](https://vercel.com)，用 GitHub 授权
2. 点击 **Add New Project**
3. 选择 `zerolang` 仓库，点击 **Import**

### 5.2 配置构建

| 配置项 | 值 |
|---|---|
| Framework Preset | **Other** |
| Root Directory | `website` |
| Build Command | `npm run build` |
| Output Directory | `build` |
| Install Command | `npm install` |

点击 **Deploy**。

### 5.3 绑定自定义域名

1. 项目 Dashboard → **Domains**
2. 输入 `zerolang.app`，点击 **Add**
3. Vercel 显示需要的 DNS 记录，复制后去域名服务商添加
4. 等待 DNS 生效

## 六、方案 C：GitHub Pages（备选）

### 6.1 启用 GitHub Pages

1. 仓库 **Settings → Pages**
2. **Source**：选择 **GitHub Actions**

### 6.2 工作流文件

`.github/workflows/deploy.yml`：

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [master]

jobs:
  build:
    name: Build Docusaurus
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: website
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm
          cache-dependency-path: website/package-lock.json
      - name: Install dependencies
        run: npm ci
      - name: Build website (all locales)
        run: npm run build
      - name: Upload Build Artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: website/build

  deploy:
    name: Deploy to GitHub Pages
    needs: build
    permissions:
      pages: write
      id-token: write
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

### 6.3 自定义域名（GitHub Pages）

在仓库 **Settings → Pages → Custom domain** 填入 `zerolang.app`，DNS 配置：

```
Type    Name      Value
A       @         185.199.108.153
A       @         185.199.109.153
A       @         185.199.110.153
A       @         185.199.111.153
```

## 七、三方案对比

| 维度 | Cloudflare Pages | Vercel | GitHub Pages |
|---|---|---|---|
| 全球 CDN | 🏆 最强（230+ 节点） | 强（100+ 节点） | 一般 |
| 域名绑定（Cloudflare DNS） | 🏆 零配置一键激活 | 需手动添加记录 | 需手动添加 4 条 A 记录 |
| 构建速度 | 中等 | 较快 | 中等 |
| 构建时间限制 | 20 分钟 | 45 分钟 | 6 小时 |
| 前端开发体验 | 良好 | 🏆 最佳 | 一般 |
| 国内访问（未备案） | 海外节点 | 海外节点 | 一般 |
| 国内访问（已备案） | 可接入合作伙伴 | 无国内节点 | 一般 |
| 自定义重定向 | `_redirects` 文件 | `vercel.json` | 不支持 |
| Analytics | 免费 Web Analytics | 免费 Web Analytics | 基础流量统计 |

## 十、常见问题

### Q1：Cloudflare Pages 构建失败

- 检查 **Build command** 是否为 `cd website && npm install && npm run build`
- 检查 **Build output directory** 是否为 `website/build`
- 查看构建日志，确认 `website/` 目录存在且 `package.json` 正确

### Q2：中文页面 404

- 确认 `docusaurus.config.ts` 中 `i18n.locales` 包含 `'zh-CN'`
- 确认 `trailingSlash: true`
- 确认 `i18n/zh-CN/docusaurus-plugin-content-docs/current/` 目录存在

### Q3：语言切换下拉框不显示

确认 `themeConfig.navbar.items` 中包含：

```typescript
{
  type: 'localeDropdown',
  position: 'right',
}
```

### Q4：自定义域名不生效

- 确认域名已在 Cloudflare 管理（Nameservers 指向 Cloudflare）
- 在 Pages 项目 → Custom domains 中确认状态为 "Active"
- 用 `dig zerolang.app` 验证 DNS 解析到 Cloudflare

### Q5：如何添加第三种语言？

见 `docs/06-架构设计.md` 中的"扩展性设计"章节。
