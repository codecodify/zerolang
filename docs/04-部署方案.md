# 部署方案

> Zerolang 中文网部署与运维指南（v2 — 面向全球多语言架构）

---

## 一、部署目标

| 环境 | 地址 | 说明 |
|---|---|---|
| 开发环境 | localhost:3000 | `npm run start`（英文默认） |
| 开发环境（中文） | localhost:3000 | `npm run start:zh` |
| 预览环境 | localhost:3000 | `npm run build && npm run serve`（所有语言） |
| 生产环境 | https://zerolang.app | GitHub Pages + 自定义域名 |
| 生产环境（备选）| https://zerolang.app | Vercel + 自定义域名 |

---

## 二、项目结构说明

站点源码位于仓库的 `website/` 子目录下：

```
repo-root/
├── docs/                    # 项目沉淀文档（非站点内容）
├── README.md
└── website/                 # Docusaurus 站点源码
    ├── config/              # 模块化配置
    ├── docs/                # 英文文档（默认语言）
    ├── blog/                # 英文博客
    ├── i18n/zh-CN/         # 中文翻译内容
    ├── src/                 # React 组件
    ├── static/              # 静态资源
    ├── package.json
    ├── docusaurus.config.ts
    └── .github/workflows/   # CI/CD
```

所有构建命令需在 `website/` 目录下执行。

## 三、多语言构建策略

### 3.1 开发时

```bash
cd website

# 只构建单个语言（快，用于日常开发）
npm run start          # 英文（默认）
npm run start:zh       # 中文
```

### 3.2 生产构建

```bash
cd website

# 构建所有语言（慢，但这是生产需要的）
npm run build
```

Docusaurus 会为每个语言生成独立目录：

```
website/build/
├── index.html              # 英文首页
├── docs/                   # 英文文档
├── blog/                   # 英文博客
└── zh-CN/                  # 中文站点
    ├── index.html
    ├── docs/
    └── blog/
```

## 四、方案 A：GitHub Pages（当前方案）

### 4.1 前提条件

- GitHub 仓库：公开仓库
- 自定义域名：`zerolang.app`（后续备案后国内可访问）
- 仓库设为 Public

### 4.2 启用 GitHub Pages

1. 进入仓库页面，点击 **Settings** → **Pages**
2. **Build and deployment** 区域：
   - **Source**：选择 **GitHub Actions**
3. 保存

### 4.3 确认工作流文件

`.github/workflows/deploy.yml` 已配置：

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [master]
  pull_request:
    branches: [master]

jobs:
  build:
    name: Build Docusaurus
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: website    # 关键：站点在 website/ 子目录
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm
          cache-dependency-path: website/package-lock.json
      - name: Install dependencies
        run: npm ci
      - name: Build website (all locales)
        run: npm run build             # 构建所有语言
      - name: Upload Build Artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: website/build

  deploy:
    name: Deploy to GitHub Pages
    needs: build
    permissions:
      pages: write
      id-token: write
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

**关键配置点：**
- `working-directory: website` — 所有命令在 `website/` 目录下执行
- `cache-dependency-path: website/package-lock.json` — 缓存锁定文件路径
- `path: website/build` — 构建产物上传路径
- `npm run build` — 构建所有语言（en + zh-CN）

### 4.4 Docusaurus 配置

`docusaurus.config.ts` 中：

```typescript
url: 'https://zerolang.app',
baseUrl: '/',
trailingSlash: true,        // 对多语言路由稳定性很重要
```

### 4.5 首次部署

```bash
git push origin master
```

进入仓库的 **Actions** 标签页，等待工作流跑完。首次部署可能需要 3-5 分钟（多语言构建更耗时）。

## 五、方案 B：Vercel

### 5.1 连接仓库

1. 登录 [vercel.com](https://vercel.com)，用 GitHub 账号授权
2. 点击 **Add New Project**
3. 选择你的仓库，点击 **Import**

### 5.2 配置构建

| 配置项 | 值 |
|---|---|
| Framework Preset | Docusaurus |
| Root Directory | `website` |
| Build Command | `npm run build` |
| Output Directory | `build` |
| Install Command | `npm install` |

### 5.3 环境变量

如需配置环境变量（如 Algolia 搜索）：

```
ALGOLIA_APP_ID=xxx
ALGOLIA_API_KEY=xxx
```

### 5.4 自定义域名

1. 项目 Dashboard → **Domains**
2. 输入 `zerolang.app`
3. 按提示在 DNS 服务商处添加记录
4. Vercel 自动配置 HTTPS

## 六、自定义域名与 DNS 配置

### 6.1 域名购买

推荐：Cloudflare Registrar（价格透明，无溢价）

### 6.2 DNS 配置

#### GitHub Pages

```
Type    Name      Value
A       @         185.199.108.153
A       @         185.199.109.153
A       @         185.199.110.153
A       @         185.199.111.153
CNAME   www       YOUR_USERNAME.github.io
```

然后在仓库 **Settings → Pages → Custom domain** 填入 `zerolang.app`，勾选 **Enforce HTTPS**。

#### Vercel

```
Type    Name      Value
A       @         76.76.21.21
CNAME   www       cname.vercel-dns.com
```

## 七、国内访问加速

`zerolang.app` 域名备案完成后，可通过以下方式加速国内访问：

| 方案 | 说明 |
|---|---|
| **Cloudflare** | 免费 CDN，改 NS 服务器即可 |
| **又拍云** | 国内节点多，免费额度够用 |
| **七牛云** | 有免费额度，需备案 |

Docusaurus 生成纯静态文件，天然适合 CDN 加速。

## 九、常见问题

### Q1：构建时间变长了

多语言构建会生成两份站点，构建时间约为单语言的 2 倍。这是正常的。

### Q2：中文页面 404

确认 `docusaurus.config.ts` 中：
- `i18n.locales` 包含 `'zh-CN'`
- `trailingSlash: true`（对多语言路由稳定性很重要）
- `i18n/[locale]/docusaurus-plugin-content-docs/current/` 目录存在

### Q3：语言切换不工作

确认 `themeConfig.navbar.items` 中包含：

```typescript
{
  type: 'localeDropdown',
  position: 'right',
}
```

### Q4：如何添加第三种语言？

见 `docs/06-架构设计.md` 中的"扩展性设计"章节。
