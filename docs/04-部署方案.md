# 部署方案

> Zerolang 社区站部署与运维指南（v3 — Vercel 主方案）

---

## 一、部署目标

| 环境 | 地址 | 说明 |
|---|---|---|
| 开发环境 | localhost:3000 | `npm run start`（英文默认） |
| 开发环境（中文） | localhost:3000 | `npm run start:zh` |
| 预览环境 | localhost:3000 | `npm run build && npm run serve`（所有语言） |
| 生产环境 | https://zerolang.app | **Vercel** + 自定义域名 |
| 生产环境（备选）| https://zerolang.app | GitHub Pages + 自定义域名 |

```

├── README.md                  # 项目级 README
├── docs/                      # 项目沉淀文档（非站点内容）
│   ├── 01-技术选型报告.md
│   ├── 02-项目规划.md
│   ├── 03-内容策略.md
│   ├── 04-部署方案.md
│   ├── 05-部署指南.md
│   └── 06-架构设计.md
└── website/                   # Docusaurus 站点源码
    ├── config/                # 模块化配置
    ├── docs/                  # 英文文档（默认语言）
    ├── blog/                  # 英文博客
    ├── i18n/zh-CN/           # 中文翻译内容

    └── docusaurus.config.ts
```

所有构建命令需在 `website/` 目录下执行。

## 四、方案 A：Vercel（推荐主方案）

Vercel 对前端静态站点的支持是业界最好的：自动 HTTPS、零配置 CDN、全球 Edge Network、分支预览、回滚等。

### 4.1 连接仓库

1. 登录 [vercel.com](https://vercel.com)，用 GitHub 账号授权
2. 点击 **Add New Project**
3. 选择 `zerolang` 仓库，点击 **Import**

### 4.2 配置构建

| 配置项 | 值 |
|---|---|
| Framework Preset | **Other** |
| Root Directory | `website` |
| Build Command | `npm run build` |
| Output Directory | `build` |
| Install Command | `npm install` |

点击 **Deploy**

首次部署约 2-3 分钟。

### 4.3 绑定自定义域名 `zerolang.app`

1. 项目 Dashboard → **Domains**
2. 输入 `zerolang.app`，点击 **Add**
3. Vercel 会显示需要的 DNS 记录，通常是：
   - 一条 **A 记录** 指向 Vercel 的 IP（如 `76.76.21.21`）
   - 或一条 **CNAME** 记录
4. 复制 Vercel 给的记录值，去你的域名服务商处添加对应 DNS 记录
5. 等待 DNS 生效（通常几分钟）
6. Vercel 自动配置 HTTPS 证书

### 4.4 启用分支预览（可选）

Vercel 默认会为每个 Pull Request 生成预览地址（如 `zerolang-git-dev-codecodify.vercel.app`），方便在合并前预览修改效果。

## 五、方案 B：GitHub Pages（备选）

如果未来 Vercel 访问不稳定，可切回 GitHub Pages。

### 5.1 启用 GitHub Pages

1. 仓库 **Settings → Pages**
2. **Source**：选择 **GitHub Actions**

### 5.2 工作流文件

`.github/workflows/deploy.yml`：

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches: [master]

jobs:
  build:
    name: Build Docusaurus
    runs-on: ubuntu-latest
    defaults:
      run:
        working-directory: website
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      - uses: actions/setup-node@v4
        with:
          node-version: 22
          cache: npm
          cache-dependency-path: website/package-lock.json
      - name: Install dependencies
        run: npm ci
      - name: Build website (all locales)
        run: npm run build
      - name: Upload Build Artifact
        uses: actions/upload-pages-artifact@v3
        with:
          path: website/build

  deploy:
    name: Deploy to GitHub Pages
    needs: build
    permissions:
      pages: write
      id-token: write
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    runs-on: ubuntu-latest
    steps:
      - name: Deploy to GitHub Pages
        id: deployment
        uses: actions/deploy-pages@v4
```

### 5.3 自定义域名（GitHub Pages）

在仓库 **Settings → Pages → Custom domain** 填入 `zerolang.app`，DNS 配置：

```
Type    Name      Value
A       @         185.199.108.153
A       @         185.199.109.153
A       @         185.199.110.153
A       @         185.199.111.153
```

## 八、常见问题

### Q1：Vercel 构建失败

检查 **Project Settings → General → Root Directory** 是否为 `website`。

### Q2：中文页面 404

- 确认 `docusaurus.config.ts` 中 `i18n.locales` 包含 `'zh-CN'`
- 确认 `trailingSlash: true`
- 确认 `i18n/zh-CN/docusaurus-plugin-content-docs/current/` 目录存在

### Q3：语言切换下拉框不显示

确认 `themeConfig.navbar.items` 中包含：

```typescript
{
  type: 'localeDropdown',
  position: 'right',
}
```

### Q4：自定义域名不生效

- DNS 记录是否已添加（用 `dig zerolang.app` 或 `nslookup zerolang.app` 验证）
- 等待 DNS 传播（最长 24 小时，通常几分钟）
- 确认 Vercel Domains 页面显示 "Valid Configuration"

### Q5：如何添加第三种语言？

见 `docs/06-架构设计.md` 中的"扩展性设计"章节。
