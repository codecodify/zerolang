## 二、翻译规范

### 术语表

| 英文原文 | 中文翻译 | 备注 |
|---|---|---|
| agent | 智能体 / Agent | 首次出现附英文 |
| graph-first | 图优先 | 保留 graph 概念 |
| semantic edit surface | 语义编辑面 | |
| ProgramGraph | 程序图 | 不翻译 |
| capability | 能力 / Capability | 保留英文 |
| effect | 副作用 / Effect | 保留英文 |
| borrow | 借用 | |
| ownership | 所有权 | |
| fallible | 可失败的 | |
| sandbox | 沙盒 | |
| diagnostic | 诊断信息 | |
| repair plan | 修复计划 | |
| skill | Skill | 不翻译，Zerolang 特有概念 |
| zero check | zero check | 命令不翻译 |
| zero graph | zero graph | 命令不翻译 |
| zero fix | zero fix | 命令不翻译 |

### 翻译风格

1. **技术术语**：优先使用中文翻译，首次出现时附英文原文
2. **命令/代码**：不翻译，保持原样
3. **专有名词**：ProgramGraph、Skill、Capability 等保留英文
4. **语气**：技术文档保持客观、准确；博客可适当轻松
5. **人称**：技术文档用"你"；教程可用"我们"
