# 部署指南

> 从零到上线的完整操作手册（v4 — Cloudflare Pages 主方案）

---

## 一、环境准备

### 1.1 安装 Node.js

Docusaurus 3.x 要求 Node.js ≥ 18，推荐 Node.js 22 LTS。

**macOS（Homebrew）：**

```bash
brew install node
node --version   # 应 ≥ v18.0.0
```

**Windows / Linux：**

从 [nodejs.org](https://nodejs.org) 下载 LTS 版本安装包。

### 1.2 安装包管理器

项目使用 npm（已随 Node.js 安装）。

---

## 二、本地开发环境搭建

### 2.1 克隆项目

```bash
git clone https://github.com/YOUR_USERNAME/zerolang.git
cd zerolang/website
```

> 注意：站点源码在 `website/` 子目录下，所有构建命令需在此目录执行。

### 2.2 安装依赖

```bash
cd website
npm install
```

### 2.3 本地预览

**英文（默认语言）：**

```bash
npm run start
```

浏览器打开 http://localhost:3000 。

**中文：**

```bash
npm run start:zh
```

浏览器打开 http://localhost:3000/zh-CN/ 。

### 2.4 本地构建验证（所有语言）

```bash
npm run build
npm run serve
```

浏览器打开 http://localhost:3000 预览构建产物。

> 多语言构建会比单语言慢，这是正常的。

---

## 三、Cloudflare Pages 部署（推荐主方案）

### 3.1 前提条件

- GitHub 仓库已创建且代码已推送
- Cloudflare 账号（免费即可）
- 域名 `zerolang.app` 已在 Cloudflare 管理（Nameservers 指向 Cloudflare）

### 3.2 创建 Pages 项目

1. 登录 [dash.cloudflare.com](https://dash.cloudflare.com)
2. 左侧菜单 **Workers & Pages**
3. 点击 **Create application**
4. 选择 **Pages** 标签
5. 点击 **Connect to Git**
6. 授权 GitHub，选择你的 `zerolang` 仓库
7. 点击 **Begin setup**

### 3.3 配置构建设置

在设置页面填写：

| 配置项 | 值 |
|---|---|
| Project name | `zerolang`（或你喜欢的名字） |
| Production branch | `master` |
| Framework preset | **None** |
| Build command | `cd website && npm install && npm run build` |
| Build output directory | `website/build` |
| Root directory | `/`（留空或不填） |

> **注意**：Cloudflare Pages 的构建命令在仓库根目录执行，所以需要 `cd website` 进入子目录后再运行 npm 命令。

点击 **Save and Deploy**，首次部署约 2-3 分钟。

### 3.4 绑定自定义域名 `zerolang.app`

1. 进入 Pages 项目 Dashboard
2. 点击 **Custom domains**
3. 输入 `zerolang.app`，点击 **Continue**
4. 点击 **Activate domain**
5. Cloudflare 自动完成 DNS 配置和 HTTPS 证书签发，**无需手动添加任何记录**

> 如果域名不在 Cloudflare 管理，Cloudflare 会显示需要添加的 DNS 记录，复制后去域名服务商处添加即可。

### 3.5 验证部署

部署完成后，检查以下 URL：

| URL | 预期内容 |
|---|---|
| `https://zerolang.app/` | 英文首页 |
| `https://zerolang.app/docs/intro/` | 英文文档首页 |
| `https://zerolang.app/zh-CN/` | 中文首页 |
| `https://zerolang.app/zh-CN/docs/intro/` | 中文文档首页 |
| `https://zerolang.app/blog/` | 英文博客 |
| `https://zerolang.app/zh-CN/blog/` | 中文博客 |

## 四、Vercel 部署（备选）

如 Cloudflare Pages 遇到构建问题，可快速切换到 Vercel。

### 4.1 连接仓库

1. 登录 [vercel.com](https://vercel.com)，用 GitHub 授权
2. 点击 **Add New Project**
3. 选择你的 `zerolang` 仓库，点击 **Import**

### 4.2 配置构建

| 配置项 | 值 |
|---|---|
| Framework Preset | **Other** |
| Root Directory | `website` |
| Build Command | `npm run build` |
| Output Directory | `build` |
| Install Command | `npm install` |

点击 **Deploy**。

### 4.3 绑定自定义域名

1. 项目 Dashboard → **Domains**
2. 输入 `zerolang.app`，点击 **Add**
3. Vercel 会显示需要的 DNS 记录，复制后去域名服务商添加
4. 等待 DNS 生效（通常几分钟到几小时）

## 五、GitHub Pages 部署（备选）

### 5.1 启用 GitHub Pages

1. 仓库 **Settings → Pages**
2. **Source**：选择 **GitHub Actions**

### 5.2 绑定自定义域名

在 **Custom domain** 填入 `zerolang.app`，DNS 配置：

```
Type    Name      Value
A       @         185.199.108.153
A       @         185.199.109.153
A       @         185.199.110.153
A       @         185.199.111.153
```

## 六、停用 GitHub Actions（如已切到 Cloudflare Pages）

不需要删除 `.github/workflows/deploy.yml`，只需：

1. 打开 https://github.com/YOUR_USERNAME/zerolang/settings/pages
2. **Source** 选 **None**
3. 保存

这样 Actions 就不会再自动部署到 GitHub Pages。

## 七、日常更新流程

```bash
cd /Users/chris/Project/zerolang/website

# 修改英文文档
vim docs/getting-started/install.md

# 或修改中文翻译
vim i18n/zh-CN/docusaurus-plugin-content-docs/current/getting-started/install.md

# 本地预览（单语言，快）
npm run start

# 提交并推送
cd /Users/chris/Project/zerolang
git add .
git commit -m "docs: update installation guide"
git push origin master
```

推送后 Cloudflare Pages 自动构建并部署，无需额外操作。

## 八、常见问题

### Q1：Cloudflare Pages 构建失败

检查构建设置：

- **Build command** 必须是 `cd website && npm install && npm run build`
- **Build output directory** 必须是 `website/build`
- **Root directory** 留空或不填（让构建在仓库根目录执行）

查看构建日志，确认 `website/` 目录存在且 `package.json` 正确。

### Q2：中文页面 404

- 确认 `docusaurus.config.ts` 中 `i18n.locales` 包含 `'zh-CN'`
- 确认 `trailingSlash: true`
- 确认 `i18n/zh-CN/docusaurus-plugin-content-docs/current/` 目录存在且有内容

### Q3：语言切换下拉框不显示

确认 `themeConfig.navbar.items` 中包含：

```typescript
{
  type: 'localeDropdown',
  position: 'right',
}
```

### Q4：自定义域名不生效

- 确认域名已在 Cloudflare 管理（Nameservers 指向 Cloudflare）
- 在 Pages 项目 → Custom domains 中确认状态为 "Active"
- 用 `dig zerolang.app` 或 `nslookup zerolang.app` 验证 DNS 解析到 Cloudflare

### Q5：搜索不工作

Algolia DocSearch 需要申请并配置 `appId`、`apiKey`、`indexName`。在申请通过前，搜索框不会生效。

### Q6：分支预览地址是什么？

Cloudflare Pages 自动为每个 Pull Request 生成预览地址：

```
https://[branch-name].zerolang.pages.dev
```
