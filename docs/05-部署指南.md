# 部署指南

> 从零到上线的完整操作手册（v3 — Vercel 主方案）

---

## 一、环境准备

### 1.1 安装 Node.js

Docusaurus 3.x 要求 Node.js ≥ 18，推荐 Node.js 22 LTS。

**macOS（Homebrew）：**

```bash
brew install node
node --version   # 应 ≥ v18.0.0
```

**Windows / Linux：**

从 [nodejs.org](https://nodejs.org) 下载 LTS 版本安装包。

### 1.2 安装包管理器

项目使用 npm（已随 Node.js 安装）。

---

## 二、本地开发环境搭建

### 2.1 克隆项目

```bash
git clone https://github.com/YOUR_USERNAME/zerolang.git
cd zerolang/website
```

> 注意：站点源码在 `website/` 子目录下，所有构建命令需在此目录执行。

### 2.2 安装依赖

```bash
cd website
npm install
```

### 2.3 本地预览

**英文（默认语言）：**

```bash
npm run start
```

浏览器打开 http://localhost:3000 。

**中文：**

```bash
npm run start:zh
```

浏览器打开 http://localhost:3000/zh-CN/ 。

### 2.4 本地构建验证（所有语言）

```bash
npm run build
npm run serve
```

浏览器打开 http://localhost:3000 预览构建产物。

> 多语言构建会比单语言慢，这是正常的。

## 三、Vercel 部署（推荐）

### 3.1 前提条件

- GitHub 仓库已创建且代码已推送
- Vercel 账号（可用 GitHub 账号登录）

### 3.2 连接仓库

1. 登录 [vercel.com](https://vercel.com)，用 GitHub 授权
2. 点击 **Add New Project**
3. 选择你的 `zerolang` 仓库，点击 **Import**

### 3.3 配置构建

| 配置项 | 值 |
|---|---|
| Framework Preset | **Other** |
| Root Directory | `website` |
| Build Command | `npm run build` |
| Output Directory | `build` |
| Install Command | `npm install` |

点击 **Deploy**，等待首次部署完成（约 2-3 分钟）。

### 3.4 绑定自定义域名 `zerolang.app`

1. 项目 Dashboard → **Domains**
2. 输入 `zerolang.app`，点击 **Add**
3. Vercel 会显示需要的 DNS 记录，复制记录值
4. 去你的域名服务商（Cloudflare / 阿里云 / 腾讯云 / Namecheap 等）添加对应 DNS 记录
5. 等待 DNS 生效（通常几分钟到几小时）
6. Vercel 自动配置 HTTPS 证书

> 不同域名服务商添加 DNS 记录的入口不同，但都是填：类型（A/CNAME）、主机记录（@ 或 www）、记录值（Vercel 给的 IP 或域名）。

### 3.5 验证部署

部署完成后，验证以下 URL 都能正常访问：

| URL | 预期内容 |
|---|---|
| `https://zerolang.app/` | 英文首页 |
| `https://zerolang.app/docs/intro` | 英文文档首页 |
| `https://zerolang.app/zh-CN/` | 中文首页 |
| `https://zerolang.app/zh-CN/docs/intro` | 中文文档首页 |
| `https://zerolang.app/blog` | 英文博客 |
| `https://zerolang.app/zh-CN/blog` | 中文博客 |

## 四、GitHub Pages 部署（备选）

如未来需要切回 GitHub Pages：

### 4.1 启用 GitHub Pages

1. 仓库 **Settings → Pages**
2. **Source**：选择 **GitHub Actions**
3. 保存

### 4.2 绑定自定义域名

在 **Custom domain** 填入 `zerolang.app`，DNS 配置：

```
Type    Name      Value
A       @         185.199.108.153
A       @         185.199.109.153
A       @         185.199.110.153
A       @         185.199.111.153
```

---

## 五、停用 GitHub Actions（如已切到 Vercel）

不需要删除 `.github/workflows/deploy.yml`，只需：

1. 打开 https://github.com/YOUR_USERNAME/zerolang/settings/pages
2. **Source** 选 **None**
3. 保存

这样 Actions 就不会再自动部署到 GitHub Pages。

## 六、日常更新流程

```bash
cd /Users/chris/Project/zerolang/website

# 修改英文文档
vim docs/getting-started/install.md

# 或修改中文翻译
vim i18n/zh-CN/docusaurus-plugin-content-docs/current/getting-started/install.md

# 本地预览（单语言，快）
npm run start

# 提交并推送
cd /Users/chris/Project/zerolang
git add .
git commit -m "docs: update installation guide"
git push origin master
```

推送后 Vercel 自动构建并部署，无需额外操作。

## 七、常见问题

### Q1：Vercel 构建失败

检查 **Project Settings → General → Root Directory** 是否为 `website`。

如果 Vercel 没有自动检测到构建输出，检查 Build Command 是否为 `npm run build`，Output Directory 是否为 `build`。

### Q2：中文页面 404

- 确认 `docusaurus.config.ts` 中 `i18n.locales` 包含 `'zh-CN'`
- 确认 `trailingSlash: true`
- 确认 `i18n/zh-CN/docusaurus-plugin-content-docs/current/` 目录存在且有内容

### Q3：语言切换下拉框不显示

确认 `themeConfig.navbar.items` 中包含：

```typescript
{
  type: 'localeDropdown',
  position: 'right',
}
```

### Q4：自定义域名不生效

- 用 `dig zerolang.app` 或 `nslookup zerolang.app` 验证 DNS 是否已生效
- 等待 DNS 传播（最长 24 小时，通常几分钟）
- 确认 Vercel Domains 页面显示 "Valid Configuration"
- 确认没有冲突的 DNS 记录（如同时有 A 记录和 CNAME 记录指向不同地方）

### Q5：搜索不工作

Algolia DocSearch 需要申请并配置 `appId`、`apiKey`、`indexName`。在申请通过前，搜索框不会生效。
