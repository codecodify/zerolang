# 部署指南

> 从零到上线的完整操作手册（v2 — 面向全球多语言架构）

---

## 一、环境准备

### 1.1 安装 Node.js

Docusaurus 3.x 要求 Node.js ≥ 18，推荐 Node.js 22 LTS。

**macOS（Homebrew）：**

```bash
brew install node
node --version   # 应 ≥ v18.0.0
```

**Windows / Linux：**

从 [nodejs.org](https://nodejs.org) 下载 LTS 版本安装包。

### 1.2 安装包管理器

项目使用 npm（已随 Node.js 安装），也可选用 pnpm：

```bash
npm install -g pnpm
```

---

## 二、本地开发环境搭建

### 2.1 克隆项目

```bash
git clone https://github.com/YOUR_USERNAME/zerolang-app.git
cd zerolang-app/website
```

> 注意：站点源码在 `website/` 子目录下，所有构建命令需在此目录执行。

### 2.2 安装依赖

```bash
cd website
npm install
```

### 2.3 本地预览

**英文（默认语言）：**

```bash
npm run start
```

浏览器打开 http://localhost:3000 。

**中文：**

```bash
npm run start:zh
```

浏览器打开 http://localhost:3000/zh-CN/ 。

修改 Markdown 文件会自动热更新。

### 2.4 本地构建验证（所有语言）

```bash
npm run build
npm run serve
```

浏览器打开 http://localhost:3000 预览构建产物。

> 多语言构建会比单语言慢，这是正常的。构建产物包含英文和中文两套站点。

## 三、GitHub 仓库初始化

### 3.1 创建仓库

1. 登录 GitHub，点击右上角 **New repository**
2. Repository name：`zerolang-app`（或其他你喜欢的名字）
3. 选择 **Public**
4. 勾选 **Add a README file**
5. 点击 **Create repository**

> 因为使用自定义域名 `zerolang.app`，仓库名不再需要和 `xxx.github.io` 格式匹配。

### 3.2 推送到远程

```bash
cd /Users/chris/Project/zerolang

git init
git add .
git commit -m "init: zerolang community site with multilingual support"

git remote add origin https://github.com/YOUR_USERNAME/zerolang-app.git
git branch -M master
git push -u origin master
```

## 四、方案 A：GitHub Pages 部署

### 4.1 启用 GitHub Pages

1. 进入仓库页面，点击 **Settings** → **Pages**
2. **Build and deployment** 区域：
   - **Source**：选择 **GitHub Actions**
3. 保存

### 4.2 确认工作流文件

项目已包含 `.github/workflows/deploy.yml`，关键配置：

```yaml
defaults:
  run:
    working-directory: website    # 站点在 website/ 子目录

# ...

- name: Build website (all locales)
  run: npm run build             # 构建所有语言

# ...

with:
  path: website/build            # 构建产物路径
```

### 4.3 首次部署

```bash
git push origin master
```

进入仓库的 **Actions** 标签页，等待工作流跑完。首次部署约需 3-5 分钟。

### 4.4 绑定自定义域名

1. 在仓库 **Settings → Pages → Custom domain** 中填入 `zerolang.app`
2. 在 DNS 服务商处添加 A 记录指向 GitHub Pages IP
3. 勾选 **Enforce HTTPS**

## 五、方案 B：Vercel 部署

### 5.1 连接仓库

1. 登录 [vercel.com](https://vercel.com)，用 GitHub 账号授权
2. 点击 **Add New Project**
3. 选择你的仓库，点击 **Import**

### 5.2 配置构建

| 配置项 | 值 |
|---|---|
| Framework Preset | Docusaurus |
| Root Directory | `website` |
| Build Command | `npm run build` |
| Output Directory | `build` |
| Install Command | `npm install` |

> 如果 Vercel 没有自动检测到 Docusaurus，手动把 Framework Preset 改成 **Other**。

### 5.3 自定义域名

1. 项目 Dashboard → **Domains**
2. 输入 `zerolang.app`
3. 按提示在 DNS 服务商处添加 A 记录或 CNAME 记录
4. Vercel 自动配置 HTTPS 证书

## 八、日常更新流程

```bash
cd /Users/chris/Project/zerolang/website

# 修改英文文档
vim docs/getting-started/install.md

# 或修改中文翻译
vim i18n/zh-CN/docusaurus-plugin-content-docs/current/getting-started/install.md

# 提交并推送
cd /Users/chris/Project/zerolang

git commit -m "docs: update installation guide"
git push origin master
```

推送后 GitHub Actions（或 Vercel）会自动构建并部署所有语言。

## 九、常见问题

### Q1：构建失败，提示 Module not found

检查 `website/package.json` 里的依赖是否完整安装：

```bash
cd website
rm -rf node_modules package-lock.json
npm install
npm run build
```

### Q2：中文页面 404

- 确认 `docusaurus.config.ts` 中 `i18n.locales` 包含 `'zh-CN'`
- 确认 `trailingSlash: true`
- 确认 `i18n/zh-CN/docusaurus-plugin-content-docs/current/` 目录存在且有内容

### Q3：语言切换下拉框不显示

确认 `themeConfig.navbar.items` 中包含：

```typescript
{
  type: 'localeDropdown',
  position: 'right',
}
```

### Q4：构建时间比原来长很多

多语言构建会生成多套站点，时间约为单语言的 2 倍。这是正常的。

### Q5：搜索不工作

Algolia DocSearch 需要申请并配置 `appId`、`apiKey`、`indexName`。在申请通过前，搜索框不会生效。
