# 项目规划

> Zerolang 中文网建站规划

---

## 一、项目目标

打造一个面向中文开发者的 Zerolang 社区门户，核心目标：

1. **文档翻译**：系统翻译 Zerolang 官方文档，降低中文开发者入门门槛
2. **社区聚合**：建立中文开发者交流阵地（博客、讨论区、QQ/微信群）
3. **生态建设**：收录 Zerolang 相关工具、库、项目、教程
4. **品牌塑造**：成为中文世界了解 Zerolang 的第一入口

---

## 二、里程碑规划

### Phase 1：MVP（第 1-2 周）

- [ ] 搭建 Docusaurus 站点框架
- [ ] 配置基础信息（标题、logo、导航、footer）
- [ ] 翻译首页与"Getting Started"章节
- [ ] 接入 Algolia DocSearch（提交申请）
- [ ] 部署到 GitHub Pages
- [ ] 注册域名（zerolang.cn / zerocn.org / zerolang-cn.github.io）

### Phase 2：内容填充（第 3-4 周）

- [ ] 翻译 CLI 命令参考文档
- [ ] 翻译语言语法文档
- [ ] 翻译标准库概览
- [ ] 发布第一篇社区博客（项目介绍）
- [ ] 配置 GitHub Actions 自动部署
- [ ] 完善 SEO（sitemap、meta 标签）

### Phase 3：社区建设（第 5-8 周）

- [ ] 建立用户交流群（QQ / 微信 / Discord 中文频道）
- [ ] 发布 Zerolang 入门系列文章
- [ ] 收录社区项目与工具
- [ ] 尝试撰写原创教程（非翻译）
- [ ] 优化站点性能与访问体验

### Phase 4：高级功能（长期）

- [ ] 接入 Zerolang 语法高亮（自定义 Prism 主题）
- [ ] 开发交互式代码示例组件
- [ ] 探索 WebAssembly 在线运行环境
- [ ] 多语言版本（en / zh-CN 切换）
- [ ] 版本化文档管理

## 三、域名策略

| 方案 | 域名 | 说明 |
|---|---|---|
| A | zerolang.cn | 最直观，但可能已被注册 |
| B | zerocn.org | 简洁，参考 mojocn.org |
| C | zerolang-cn.github.io | 免费，先用这个 |
| D | zerolang.dev | 开发者域名，Vercel 系 |

**建议**：先用 GitHub Pages 免费域名上线，后续注册 zerocn.org 或 zerolang.cn 做主力域名。

---

## 四、内容更新策略

Zerolang 目前处于极早期（v0.1.4），官方文档变化频繁。需要设计同步机制：

1. **定期拉取**：每周检查 zerolang.ai 文档更新
2. **变更追踪**：用 Git diff 追踪官方文档变化
3. **版本标注**：每篇翻译文档标注"基于 Zerolang vX.Y.Z"
4. **待更新标记**：官方文档大幅更新时，在页面顶部加 banner 提示

## 五、角色分工（初期）

| 角色 | 职责 |
|---|---|
| 站长 | 站点维护、部署、域名管理 |
| 翻译组 | 官方文档翻译、校对 |
| 内容组 | 博客撰写、教程编写 |
| 社区组 | 社群运营、活动组织 |

## 六、风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| Zerolang 项目停止维护 | 高 | 保持轻量投入，关注官方动态 |
| 官方文档变化过快 | 中 | 设计版本化文档，允许滞后更新 |
| 翻译人力不足 | 中 | 优先翻译核心章节，其余用机器翻译+人工校对 |
| 域名被抢注 | 低 | 尽快注册意向域名 |
